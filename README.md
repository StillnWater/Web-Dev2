# Web-Dev2

A collection of web development projects exploring modern JavaScript frameworks, responsive design, and front-end development practices.

## 📋 Overview

This repository contains multiple web development projects built with JavaScript, CSS, and HTML. It serves as a learning playground and portfolio of web development work, with a primary focus on React-based applications using modern tooling.

**Language Composition:**
- JavaScript: 47.4%
- CSS: 34.2%
- HTML: 18.4%

## 🚀 Projects

### ReactBlog
A blog application built with **React** and **Vite**, featuring:
- Fast development with Vite's Hot Module Replacement (HMR)
- ESLint configuration for code quality
- Support for multiple React compilation options
- Modern build setup with optimized performance

**Tech Stack:** React, Vite, JavaScript

### React_Playground
A learning project for mastering React fundamentals:
- Component naming conventions and best practices
- React's diffing algorithm and reconciliation
- Module import/export patterns
- Component composition examples

**Key Learnings:**
- Component names must start with a capital letter
- Default exports limited to one component per file
- Named exports for multiple component exports

## 🛠️ Technologies

- **Frontend Framework:** React
- **Build Tool:** Vite
- **Languages:** JavaScript, HTML, CSS
- **Development:** ESLint, HMR (Hot Module Replacement)

## 📦 Getting Started

Each project folder contains its own setup. Navigate to the desired project:

```bash
cd ReactBlog
# or
cd React_Playground
```

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

## 💡 Key Concepts

This repository demonstrates:
- Modern React development practices
- Component-based architecture
- Vite's superior development experience
- CSS styling techniques
- Responsive web design

## 📝 Notes

- Ensure component names follow PascalCase convention
- Use default exports sparingly; prefer named exports
- Refer to individual project READMEs for specific setup instructions
